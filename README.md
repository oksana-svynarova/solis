# Solis Landing Page

A main single-page landing site and a custom 404 error page with light/dark theme support.

## Features
- **Light/Dark mode toggle** implemented with vanilla JavaScript and CSS variables.
- **Optimized images**: WebP and SVG sprite for better performance.
- **Responsive design** for mobile, tablet and desktop.
- **Custom 404 error page** with its own SCSS styles.

## Technologies
- **HTML5** – semantic markup.
- **SCSS** – variables, mixins and modular structure for maintainable styles.
- **Vanilla JavaScript** – handles theme switching and video logic.
- **GitHub Pages** – for hosting the live demo.
